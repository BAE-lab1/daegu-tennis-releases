# 대구 테니스 · Windows 설치판

[최신 설치 파일 다운로드](https://github.com/BAE-lab1/daegu-tennis-releases/releases/latest)

Python이나 설치 BAT 없이 설치 EXE를 실행하면 됩니다. 설치 후 바탕화면의 Daegu Tennis 바로가기로 시작합니다.

이 저장소에는 설치 파일과 업데이트 정보만 배포합니다. 개발 소스 저장소는 비공개로 유지합니다. 계정 정보, 예약 정보, 로그는 배포에 포함하지 않습니다.

## 업데이트

1.34.1부터 프로그램 시작 시 공식 업데이트 정보를 백그라운드에서 확인합니다. 업데이트 창에서 자동 설치를 켜면 예약·대기·알림 작업이 끝난 뒤 설치하고 다시 시작합니다. 기존 설정은 유지됩니다.

기존 1.34.0 사용자는 1.34.1 설치 파일을 한 번 실행해야 기본 업데이트 주소가 연결됩니다.

공식 업데이트 주소: https://github.com/BAE-lab1/daegu-tennis-releases/releases/latest/download/update.json

실제 예약 가능 여부와 접수 결과는 각 시설 공식 사이트가 기준입니다.
